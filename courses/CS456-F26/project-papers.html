Vroom's evaluation is built on Mahimahi, an open-source platform for recording and replaying web page loads under emulated network conditions. Vroom's own changes were not released, so you would add them on top of Mahimahi. If you choose this paper, you only need to reproduce the paper's results; no further analysis is needed.
